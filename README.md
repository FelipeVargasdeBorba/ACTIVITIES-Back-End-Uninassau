# 📝 Atividades e Provas – Programação Orientada a Objetos (POO) em Java

Este repositório contém todas as atividades, exercícios, listas e provas desenvolvidas para a disciplina de **Programação Orientada a Objetos (POO)** na faculdade da Uninassau.  
O objetivo é registrar minha evolução na linguagem **Java** e aplicar conceitos fundamentais da programação orientada a objetos.

---

## 🚀 Conteúdos Trabalhados

As atividades presentes aqui abordam tópicos clássicos de POO em Java, como:

- ✔️ Classes e Objetos  
- ✔️ Encapsulamento  
- ✔️ Construtores  
- ✔️ Herança  
- ✔️ Polimorfismo  
- ✔️ Interfaces  
- ✔️ Métodos e Sobrecarga  
- ✔️ Coleções (ArrayList, etc.)  
- ✔️ Tratamento de Exceções  

---

## 🛠️ Tecnologias Utilizadas

- **Java** (versão utilizada na disciplina)  
- **IDE**: Intellij
- **Git/GitHub** para controle de versão

---

## 🎯 Objetivo do Repositório

- Registrar minha evolução na disciplina  
- Facilitar revisões futuras  
- Armazenar soluções de forma organizada  
- Demonstrar habilidades práticas com Java e POO

---

## 📚 Sobre a Disciplina

A disciplina de **Programação Orientada a Objetos** tem como foco entender e aplicar os princípios que permitem criar softwares modulares, reutilizáveis e bem estruturados utilizando a linguagem Java.
